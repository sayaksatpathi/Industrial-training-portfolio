## Overview

A clean, responsive portfolio website that documents an **IT Service Portal** project delivered during industrial training. It presents the work across several pages — an overview of the project, the IT services offered, a project/portfolio showcase, a service-request form, and contact & location details — as a self-contained static site.

## 📄 Pages & Sections

- 🏠 **Home / About This Project** — what was built and why
- 🛠️ **Our IT Services** — the catalogue of services
- 💼 **Projects & Portfolio** — showcased work
- 📝 **Submit a Service Request** — an interactive request form
- 📍 **Contact & Location** — how to get in touch
- 🚀 A closing call-to-action to start a new IT project

## 🧱 Tech Stack

- **HTML5 + CSS3 + vanilla JavaScript** (`index.html`, `styles.css`, `app.js`)
- Fully static — deploys anywhere (currently on **Vercel**)
- Responsive, lightweight, no build step required

## 🚀 Run Locally

```bash
# any static server works, e.g.:
npx serve .
# or simply open index.html in a browser
```
